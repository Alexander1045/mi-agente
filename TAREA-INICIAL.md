# Tarea inicial para OpenCode

Abre esta carpeta como proyecto local. Lee primero `AGENTS.md` completo y revisa la fuente que está en `android/`.

**Por ahora solo audita.** No edites, compiles sobre instalaciones del usuario, despliegues, publiques código ni conectes servicios. Entrega: (1) inventario de funciones, (2) archivos faltantes para compilar como proyecto Android, (3) fallos reproducibles y pruebas recomendadas, (4) riesgos de package ID/firma/datos y (5) plan de implementación priorizado, con estimación de herramientas y costos si corresponde. Espera autorización antes de implementar o crear infraestructura.

La APK incluida es solo de referencia para comparar. No se probó en el Xiaomi del usuario. No des por hecho que actualiza otra instalación. No modifiques ni solicites exportar datos personales durante la auditoría.
